# 第4章：Map・Setの更新と変換（編集用／読者ZIPには含めない）

## Map.set・Map.del

`49_map_update_delete.bend` は、`wins=7` と `games=10` を登録した後、`wins` を8に上書きし、`games` を削除します。残るキーは `wins` だけです。`Map.get` は8、`Map.has("games")` は偽、`Map.size` は1を返すので、結果は `8 + 0 + 1 = 9` です。

- 上書き値を12に変えると、`12 + 0 + 1 = 13` です。
- 削除対象を `"not-found"` にすると `games` が残り、存在判定は真、サイズは2となります。結果は `8 + 1 + 2 = 11` です。

`Map.get` と `Map.has` の返り値にはMap自体も含まれます。複数回調べるなら返ってきたMapを次へ渡します。`Map.size` はMapを消費します。

## Set.from_list・Set.to_list

`50_set_from_list.bend` の入力は3要素ですが、重複した `"0,0"` は一つとして扱われ、集合の要素数は2です。存在しない `"3,3"` の削除は集合を変えません。

- 削除対象を `"1,1"` にすると、`"0,0"` のみが残り、`1n` を返します。
- 入力に `"2,2"` を加え、削除対象を元の `"3,3"` のままにすると、`3n` を返します。

`Set.to_list` は入力順を復元するAPIではありません。順序が必要なときは別途並べ替えます。
