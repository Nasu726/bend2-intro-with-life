# 第22章補稿：任意個数の公開数字を反復する（TeX・PDF未統合）

## なぜ三数字版と四数字版を統合するのでしょうか

これまでは公開数字が一つ増えるたびに、Bendの関数の引数と処理を増やしていました。実際のN×N盤面では公開数字の個数が変わるため、`Clue{index,value}`のリストを受け取る形に改善します。元の「残り地雷数0なら安全、未知マス数と等しければ地雷」の規則は変更しません。

## Bendのコードと出力

`intermediate/minesweeper/nxn_public_many_fixpoint.bend` を使います。

```bend
type Clue is Type:
  Clue{index: U32, value: U32}

def main() -> U32:
  Fix.score(infer_many(3, [Clue{1, 1}, Clue{2, 0},
                           Clue{4, 1}, Clue{5, 0}],
                       10n, Nil{}, [1, 2, 4, 5]))
```

```sh
bend intermediate/minesweeper/nxn_public_many_fixpoint.bend --check-only
bend intermediate/minesweeper/nxn_public_many_fixpoint.bend
# 6
```

期待値`6`は教材専用の符号`100×地雷確定数＋安全確定数`です。公開済みの1・2・4・5番に加え、7・8番が安全と確定します。隠された正解配置は推論器へ渡しません。

## 反復の仕組みと停止条件

公開数字は`List<&2, Clue>`に保存します。`one_round`はリストを再帰的に走査して既存の`Rule.infer`を各数字に適用し、地雷・安全の確定集合を引き継ぎます。`after_round`は一巡して集合に増分がなければその場で終了します。

N×N盤面では新しく確定できるマスは最大N²個であり、変化する周回には必ず新しいマスが一つ以上あります。したがって`N²+1`回の燃料は収束の十分条件です。指定燃料が足りなければ`Limit`を返し、成功と誤認しません。

公開数字の位置は初期安全集合に含める必要があり、同じ公開マスの重複・盤外・不可能な値を拒否します。初期集合の重複・盤外・矛盾がないこと、公開済み以外の確定情報が正しいことは呼び出し元の契約です。プレイヤーの旗は地雷確定の根拠ではありません。

これは**公開数字の個数を一般化した単独制約の固定点**であり、複数制約を連立して得る結論、全盤面の充足可能性、一般N×Nの運ゲー無し生成は保証しません。

まず公開数字を空リストにして何も確定しないことを確かめてみましょう。次に公開数字`(0,0),(2,1),(6,1)`の三つへ変えて期待値`206`を得てみましょう。最後に反復燃料を`1n`へ減らし、`Limit`になる局面とならない局面を比較してみましょう。
