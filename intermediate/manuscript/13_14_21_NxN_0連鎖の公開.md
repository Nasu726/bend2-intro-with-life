> **TeX本編・PDFには未統合**。この節の対象は、地雷配置済みN×N盤面の0連鎖を処理するBendの純粋関数です。初手安全の `Fresh`、自動的な `Won` 遷移、GUIはまだ接続していません。

## なぜ1マスずつ開くだけでは足りないのでしょうか

地雷がない2×2盤面を考えます。左上をクリックしたとき、数字0の周囲も安全だと分かります。そこからさらに0の周囲を調べれば、残りの3マスも一度に開けます。通常のマインスイーパーでは、0のマスを開いたらこの連鎖を自動的に行います。

しかし、すでに旗を立てたマスまで開いてはいけません。また、10×10の右端と次の行の左端は隣ではありません。前節の `nxn_neighbors.bend` を使い、正しい近傍だけを調べましょう。

## Bendコードと実行結果

`minesweeper/nxn_flood.bend` は `Step.Session` を受け取り、0のマスから安全な領域を広げた状態を返します。

```bend
def next_work(zero: Bool, +n: U32, +index: U32, rest: List<U32>) -> List<U32>:
  match zero:
    case True{}:
      prepend_all(Neighbors.neighbors(n, index), rest)
    case False{}:
      rest
```

数字が0なら近傍を次の仕事として追加し、1以上ならそのマスだけを開いて止まります。たとえば次の `main` は、地雷のない2×2盤面で左上をクリックし、右下の状態を読みます。

```bend
def main() -> U32:
  Step.snapshot(click(Step.new(Words.new(2)), 0), 3)
```

```sh
bend intermediate/minesweeper/nxn_flood.bend
# 10
```

`10` は右下が数字0で公開されたことを表します。単一マス公開だけなら右下は `0`（未公開）のままです。

## どのように止まるのでしょうか

`explore` は `List<U32>` に積んだ添字を一つずつ取り出します。未公開で安全なマスだけを公開し、その数字が0なら近傍を追加します。すでに開いたマスと旗は変更しません。同じマスが作業リストに重複していても、公開済みなら再度近傍を追加しません。

各0マスは高々一度だけ公開され、近傍を追加する回数は最大8回です。最初のクリックを合わせても取り出す仕事は `1 + 8*n*n` 回以下です。そこで `Nat` の燃料をこの数に設定し、再帰のたびに1減らします。停止性はこの上限で保証し、配列の余剰スロットは `Geo.valid_index` で拒否します。

`scripts/test_nxn_flood.py` はBendの実行結果を、Pythonの座標計算とキューによる独立参照モデルに照合します。開いた数字、旗、敗北、盤外、既存の勝利判定器との組合せを**有限ケースで**検査します。すべての盤面に対する形式的証明や、10×10 GUIの実機確認ではありません。
