# 第13〜14・21章補稿：勝利判定は「安全マスをすべて開いたか」

## なぜ旗の数では勝利を決められないのでしょうか

マインスイーパーでは、地雷に旗を立てることはプレイヤーの補助操作です。正しい地雷すべてに旗が立っていても、安全なマスが一つ残っていればゲームはまだ終わりません。反対に、地雷へ旗を立てなくても、すべての安全なマスを公開すれば勝ちです。

たとえば2×2盤面で地雷が右下（添字3）にある場合を考えましょう。0、1、2を開けば、3に旗を立てなくても勝利条件を満たします。一方、0に旗を立てたまま1、2を開いても、0が未公開なので勝利ではありません。

## Bendコードと実行結果

`minesweeper/nxn_victory.bend` は、既存の`Step.Session`を受け取り、資源としての盤面を返しながら勝利条件の真偽を計算します。

```bend
def square_ok(square: Game.Square, mined: Bool) -> Bool:
  match square:
    case Game.Hidden{}:
      mined
    case Game.Flag{}:
      mined
    case Game.Open{clue}:
      Bool.not(mined)
```

地雷マスは`Hidden`でも`Flag`でもかまいません。安全マスは必ず`Open`でなければなりません。さらに、地雷しかない盤面が空虚な全称条件で勝ちにならないよう、少なくとも一つの安全マスが存在したかも記録します。

```bend
def main() -> U32:
  board = Words.set_checked(Words.new(2), 3, True{})
  game = Step.click(Step.click(Step.click(Step.new(board), 0), 1), 2)
  verdict(inspect(game))
```

```sh
bend intermediate/minesweeper/nxn_victory.bend
# 1
```

`1`は勝利条件が成立すること、`0`は未成立であることを示します。これは**判定結果**であって、`Step.Session`の`Playing`を`Won`へ変更した結果ではありません。

## 仕組みを追いましょう

`scan`は`Nat`燃料を`n*n`に設定し、論理添字0から順に調べます。`Array`の容量は2の累乗に切り上げられますが、たとえば10×10の100〜127番の余剰スロットは走査しません。安全な未公開マスが見つかれば早期終了します。

`Words.has`と`Array.get`はいずれも格納資源を消費・返却するため、`Scan`に両方を保持し、最後に元の`Step.Session`へ組み直します。`Lost`は無条件に不成立です。真の地雷位置は**ゲーム内部での勝利判定だけ**に使用し、公開情報ソルバーには渡しません。

`scripts/test_nxn_victory.py`は、Bend実行結果をPythonの集合による独立参照モデルと有限照合します。初手安全移動、0連鎖、全称証明はこのテストの対象外です。
