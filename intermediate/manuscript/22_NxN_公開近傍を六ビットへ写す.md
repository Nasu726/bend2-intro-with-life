# 第22章補稿：公開近傍を六ビット制約へ写す（TeX・PDF未統合）

## マス番号とビット位置は違う

公開数字の周囲にある未知マスを列挙できても、その番号をそのまま六ビット推論器へ渡すことはできません。盤面の8番と「ビット5」は違います。ビット5は、あらかじめ並べた六つの未知マスのうち六番目を指します。この対応を間違えると、別の制約を解いてしまいます。

## 実際にBendコードを動かす

`intermediate/minesweeper/nxn_public_six_mask.bend` の `mask_for` は、公開済みの数字の位置・公開マス一覧・六つの未知マス一覧を受け取り、未知近傍を六ビットへ変換します。真の地雷配置や未検証の旗は受け取りません。

```bend
def main() -> U32:
  tag(mask_for(3, 0, [0, 2, 7], [1, 3, 4, 5, 6, 8]))
```

```sh
bend intermediate/minesweeper/nxn_public_six_mask.bend --check-only
bend intermediate/minesweeper/nxn_public_six_mask.bend
# 7
```

3×3盤面で0・2・7番が公開済みなら、未知マスは `(1,3,4,5,6,8)` です。0番の未知近傍は `(1,3,4)` なので、ビット位置0・1・2を立てた `1+2+4=7` を返します。同じ `mask_for` で数字2番と7番を調べると13と62です。これは既存の三数字推論器 `nxn_public_three_small.bend` の集合引数 `(7,13,62)` に一致します。

## 仕組みと失敗の扱い

`bit_of` は六マスのリストから添字の位置を探し、対応する2の累乗を返します。`encode` は未知近傍を一度ずつ消費して `U32.or` でビットを結合します。六マスに含まれない近傍があれば黙って無視せず `Invalid{}` を返します。

`universe` の長さが六つ以外、重複・非昇順・盤外・公開済みのマスを含む場合や、数字のマスが未公開の場合も拒否します。有効な空集合のマスク0と無効な入力は区別し、表示用 `tag` では後者を64とします。公開済みマス一覧自体は重複なし・昇順・範囲内であることを前提にしています。

Bend 2.0.39では、計算途中の値をそのまま `match` の対象にできません。`choose_bit`・`encoded_with_bit`・`finish_if` のように、分岐したい値を別の関数の引数に渡してから `match` します。これは推論規則を変更するためではなく、Bendの型検査を通すための書き方です。

さらに、中央4番だけでなく7・8番も公開した3×3盤面では、未知近傍6マスのビットがすべて立ち `63` になります。4×4盤面で0・1・4・5番が公開済みなら、0番の未知近傍は空なので `0` です。`Invalid` の表示値 `64` と混同しないようにしましょう。
