# 第22章補稿：二つの公開数字の差集合で固定点の限界を越える（TeX・PDF統合済み）

## なぜ単独数字を何度調べても進まないのでしょうか

前の実習では、公開数字を`List<&2, Clue>`で受け取り、数字ごとの単独規則を固定点まで反復しました。しかし「これ以上増えない」は「安全マスが存在しない」ことではありません。二つの公開数字を**同時に**見ると、単独規則では見えなかった確定情報が得られる場合があります。

3×3盤面で公開数字が`(1,1)`と`(4,1)`の二つだとします。数字の位置である1・4番はすでに安全です。1番の未知近傍は`A={0,2,3,5}`、4番の未知近傍は`B={0,2,3,5,6,7,8}`です。どちらの数字も1なので、`A`にも`B`にも地雷がちょうど一つあります。

## Bendで差集合を調べてみましょう

`intermediate/minesweeper/nxn_public_pair_gap.bend`は、既存の可変個数推論器と部分集合推論器を同じ公開状態に適用する教材です。

```bend
+single = Fix.score(Many.infer_many(
  3, [Many.Clue{1, 1}, Many.Clue{4, 1}],
  10n, Nil{}, [1, 4]))
+extra = safe_count(Subset.infer(
  [0, 2, 3, 5], [0, 2, 3, 5, 6, 7, 8], 1, 1))
(100 * single + extra : U32)
```

```sh
bend intermediate/minesweeper/nxn_public_pair_gap.bend --check-only
bend intermediate/minesweeper/nxn_public_pair_gap.bend
# 203
```

出力`203`はこの教材専用の符号です。`200`は単独規則で確定済みの安全マスが公開位置の**2個のみ**であることを示し、末尾の`3`は部分集合規則が追加で**3個**の安全マスを見つけたことを示します。地雷マス番号203ではありません。

## なぜ6・7・8番が安全と分かるのでしょうか

`A⊂B`で、どちらにも地雷が1個です。`B`にあって`A`にない部分は`B＼A={6,7,8}`です。もしこの三マスのどれかが地雷なら、`B`の地雷数は`A`より多くなってしまいます。したがって三マスはすべて安全です。

逆向きの例もあります。公開数字`(4,4)`と`(7,1)`では、単独規則は進めません。しかし4番の未知近傍から7番の未知近傍を引くと`{0,1,2}`が残り、残り地雷数の差は`4-1=3`です。この三マスはすべて地雷です。**安全を確定する規則と、地雷を確定する規則は対称**です。

このBendサンプルは二つの固定された公開数字について、手計算で得た未知近傍集合を`Subset.infer`に渡します。任意の公開状態から自動的に全ペアを抽出・反復する完成ソルバーではありません。

## 実行結果を独立に確かめましょう

`python3 intermediate/scripts/test_nxn_public_pair_gap.py`は、3×3盤面で公開数字がちょうど二つの**560種類の公開状態**を独立に列挙します。単独数字規則が一手も増やせず、部分集合規則なら確定できる公開状態は**48種類**あり、うち**24種類が安全マス、24種類が地雷マス**を新たに確定します。二つの例はいずれも、公開数字と矛盾しない地雷配置が4通りで、全候補で結論が一致します。

テストはこの48種類から導出した未知近傍集合・残り地雷数を使い、独立Pythonの全候補オラクルとBendの`Subset.infer`の出力集合を照合します。`python3 -m unittest intermediate.tests.test_nxn_public_pair_gap -v`はPython側の有限監査です。これらは**3×3の二公開数字に限定した有限検証**であり、Bendの全560状態実行、一般N×Nの形式的証明、連立推論の完全性、運ゲー無し盤面生成を意味しません。

まず二つの公開数字の近傍集合を紙に書き、6・7・8番が安全になることを説明してみましょう。次に`(4,4)`と`(7,1)`の例で0・1・2番が地雷になる理由を確かめてみましょう。最後に、公開数字の近傍が互いに包含関係にない場合、なぜこの単純な差集合規則だけでは判定できないのか考えてみましょう。
