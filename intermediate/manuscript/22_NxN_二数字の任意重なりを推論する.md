# 第22章補稿：二つの公開数字が包含しなくても推論できる（TeX・PDF未統合）

## なぜ差集合だけでは足りないのでしょうか

前の実習では、二つの公開数字の未知近傍が包含関係にあるとき、地雷数の差から安全マスや地雷を確定しました。しかし実際の盤面では、二つの近傍が一部だけ重なることもあります。その場合、単純な包含差集合規則は使えません。**共通部分の地雷数に上下限を付ける**と、さらに先へ進めます。

3×3盤面で0番が数字2、2番が数字1として公開された局面を考えましょう。公開済みの0・2番を除く未知近傍は、`A={1,3,4}`と`B={1,4,5}`です。どちらも相手を包含しません。

## Bendコードを動かしてみましょう

既存の`nxn_public_overlap.bend`は、二つの集合が包含しない場合も扱う純粋な推論部品です。公開数字の位置から未知近傍を作る処理とは分離しています。今回の`nxn_public_overlap_witness.bend`では、上の公開局面をその部品へ渡します。

```bend
def main() -> U32:
  score(Overlap.infer([1, 3, 4], [1, 4, 5], 2, 1))
```

```sh
bend intermediate/minesweeper/nxn_public_overlap_witness.bend --check-only
bend intermediate/minesweeper/nxn_public_overlap_witness.bend
# 101
```

この`101`は教材専用の符号です。`100 × 確定安全マス数 + 確定地雷マス数`を表し、安全1マス（5番）・地雷1マス（3番）を意味します。地雷位置101番でもゲームの得点でもありません。

## 共通部分の地雷数を挟み撃ちする

`I=A∩B={1,4}`、`X=A＼B={3}`、`Y=B＼A={5}`とします。`I`にある地雷の数を`t`と置くと、公開数字から`t+地雷数(X)=2`、`t+地雷数(Y)=1`です。`X`と`Y`はいずれも1マスなので、両式を同時に満たすには`t=1`しかありません。したがって`X`の3番は地雷、`Y`の5番は安全です。`I`の1・4番のどちらが地雷かまでは分かりません。

一般には`x=|A＼B|`、`y=|B＼A|`、`i=|A∩B|`、残り地雷数を`r_A,r_B`とすると、共通部分の地雷数`t`は次の範囲に入ります。

```text
max(0, r_A - x, r_B - y) <= t <= min(i, r_A, r_B)
```

下限が上限を超えたら二つの制約は矛盾します。そうでなければ、`t`の上限・下限から各領域の地雷数の上下限が求まります。ある領域の地雷数の**上限が0**なら全マス安全、**下限が領域の大きさ**なら全マス地雷です。入力集合は重複なし・昇順で、既に確定した安全・地雷マスを除いた公開情報から作ります。プレイヤーが立てた旗を証拠にはしません。

## 560公開状態を独立に確かめる

`python3 intermediate/scripts/test_nxn_public_pair_overlap_audit.py --model-only`は、3×3でちょうど二つの数字を公開した**560種類の公開状態**を、実際の地雷配置の全候補から構成します。独立の全候補オラクルと二制約のPython参照モデルは、両数字の未知近傍の和集合上で**560状態すべて一致**します。

単独数字の固定点反復より新しい確定が得られるのは**88状態**です。その内訳は包含関係がある48状態と、包含関係がない**40状態**です。安全が新たに確定する状態は64、地雷が新たに確定する状態も64で、両方が確定する状態を重複して数えています。Bend実行回帰では、包含関係がない40状態から導出した集合と数字を`Overlap.infer`へ渡し、出力集合まで照合します。

`python3 intermediate/scripts/test_nxn_public_pair_overlap_audit.py`はこの40条件のBend型検査・実行照合と上の`101`の実行例も検査します。**560状態の全列挙はPython側のみ**であり、Bendで560状態すべてを実行したわけではありません。さらに、この二制約の一致は一般N×Nの全公開数字を連立した完全推論、運ゲー無し生成、GUI実機の検証を意味しません。

まず`A={1,3,4}`と`B={1,4,5}`の地雷配置を列挙し、3番と5番の結論が変わらないことを確かめてみましょう。次に数字を逆にした`(0,1),(2,2)`を考え、どのマスの結論が逆転するか調べてみましょう。最後に、共通部分の地雷数が一意に定まらないとき、上下限だけで確定できる領域と、確定できない領域を区別してみましょう。
