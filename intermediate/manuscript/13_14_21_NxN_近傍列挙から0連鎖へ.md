# 第13〜14・21章補稿：0連鎖の前に近傍を列挙する

> **TeX本編・PDFには未統合**。N=2〜100の近傍リストだけを検証します。公開、0連鎖、勝利判定、GUI操作はまだ実装していません。

## なぜ近傍をリストにするのでしょうか

0のマスを開いたら、その周囲のマスを次の調査対象に追加します。しかし10×10盤面の右端と次の行の左端は、配列の添字が連続していても隣接していません。そこで、公開処理に入る前に「本当に隣接するマスだけを列挙する」小さな関数を作りましょう。

## Bendコードと実行結果

`minesweeper/nxn_neighbors.bend` は既存の `Geo.neighbor` を使い、3×3の9位置から中央と盤外を除外します。

```bend
def neighbors(+n: U32, +index: U32) -> List<U32>:
  if_valid(Geo.valid_index(n, index), n, index)

def main() -> U32:
  count(neighbors(10, 0))
```

```sh
bend intermediate/minesweeper/nxn_neighbors.bend
# 3
```

10×10の左上（添字0）の隣は1、10、11の3マスです。中心の44番なら35、43、45、53、54、55など、最大8マスになります。実際の返り値は添字の昇順です。

## 仕組みを追いましょう

`offsets` は `Nat` の燃料9から始まり、位置8から0へ一つずつ調べます。範囲内の隣だけを `List` の先頭へ追加するので、結果は昇順になります。座標0での符号なし減算は大きな `U32` に回り込みますが、`Geo.neighbor` が盤外を拒否するため `Geo.index` を呼びません。無効なサイズ、100〜127の配列余剰添字（N=10）も空リストにします。

`scripts/test_nxn_neighbors.py` はBendの返す**順序も含むリスト全体**を、独立したPython座標計算と有限照合します。単に件数が一致しただけでは成功にしません。
