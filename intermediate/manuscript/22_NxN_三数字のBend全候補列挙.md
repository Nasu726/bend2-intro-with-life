# 第22章補稿：三数字を同時に調べるBendの六変数実習（TeX・PDF未統合）

## 二数字の規則では見つからない確定手

第22章で使った3×3の例では、公開数字0・2・7がいずれも1で、地雷総数は2個です。二数字だけを組み合わせても確定手がありません。しかし、三数字を同時に満たす配置をすべて調べると、1番は地雷、3・4・5番は安全と分かります。

今回はこの差を、**六つの未知マスに限定したBendの全候補列挙**で確かめます。盤面の真の地雷配置を渡さず、公開数字から得た三つの集合と残り地雷数だけを渡します。

## 実際に動かすBendコード

`intermediate/minesweeper/nxn_public_three_small.bend` は、六つの未知マスを6ビットの `U32` で表します。実盤面の添字 `(1,3,4,5,6,8)` を、ビット位置 `(0,1,2,3,4,5)` に対応させます。

| 公開数字 | 未知隣接マス | 6ビット集合 | 必要な地雷数 |
| --- | --- | ---: | ---: |
| 0番の1 | {1,3,4} | 7 | 1 |
| 2番の1 | {1,4,5} | 13 | 1 |
| 7番の1 | {3,4,5,6,8} | 62 | 1 |

```bend
def main() -> U32:
  score(infer(7, 13, 62, 1, 1, 1, 2, True{}))
```

```sh
bend intermediate/minesweeper/nxn_public_three_small.bend --check-only
bend intermediate/minesweeper/nxn_public_three_small.bend
# 341
```

`341` は表示用の `models * 100 + safe * 10 + mines` です。整合する候補が2通り、確定安全ビット集合が14、確定地雷ビット集合が1であることを示します。**341個の安全マスという意味ではありません。** ビット集合14は位置1・2・3、つまり実盤面の3・4・5番です。

## 仕組み：64通りを最後まで検査する

`scan(64n, ...)` は六変数の全 `2^6=64` 通りを調べます。`fits` は各候補について、三つの公開数字の残り地雷数と、必要に応じて総地雷数を検査します。条件を満たした候補の**和集合**に現れないビットは確定安全、**共通部分**に残るビットは確定地雷です。

候補が一つもなければ `Inconsistent` を返します。調べる数を途中で打ち切って安全と断定することはありません。`use_total=False{}` の場合は `total` を無視します。同じ三数字でも総地雷数を使わないと候補は3通りになり、安全ビット集合は10、確定地雷は0になります。総地雷数を公開情報として使ったかどうかを、引数で明示する設計です。

`scripts/test_nxn_public_three_small.py` は独立したPython全列挙とBendの型検査・実行結果を照合します。固定の3×3幾何では全64地雷割当×総地雷数の有無を照合し、さらに任意の六ビット集合三つと矛盾入力も検査します。 Bendの実行照合は、全ケースを一つの巨大な式にせず、**最大4ケースずつの独立プログラム**に分割します。全ケースを残したまま実行時間を抑えるためで、ソルバーの能力を増やすものではありません。

## 演習

1. `True{}` を `False{}` に変え、`total` を無視すると安全・地雷の結論がどう変わるか、`score` だけでなく `Forced` の各フィールドを調べてみましょう。
2. 公開数字の集合 `(7,13,62)` を紙に書き、三数字の条件を満たす候補が `{1,6}` と `{1,8}` だけになることを確かめてみましょう。
3. `a=64` を渡すと `Inconsistent` になる理由を、入力検査から探してみましょう。
4. `python3 intermediate/scripts/test_nxn_public_three_small.py` を実行し、六ビット集合と3×3盤面の独立列挙が一致することを確かめてみましょう。

**検証の境界：** このBend実装は「最大六つの未知マスに対する三つの集合制約」の全列挙です。公開盤面から未知隣接集合を自動抽出する機能、三数字より多い一般連立制約、任意のfrontierサイズ、N×Nの自動ゲーム再生・運ゲー無し生成器、GUI実機検収は含みません。型検査・有限実行照合と全称証明は別です。読者用ZIPには検証用Pythonや解答を含めず、TeX/PDF本編への統合も別の検収ゲートです。
