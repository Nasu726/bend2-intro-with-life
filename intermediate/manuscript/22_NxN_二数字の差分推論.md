# 第22章補稿：二つの公開数字から差を取る（TeX・PDF未統合）

## なぜ数字を一つずつ見ているだけでは足りないのでしょうか

3×3の盤面で、0番と1番を開いたところ、どちらも数字が1でした。
0番の未確定な隣接マスが **3・4番**、1番の未確定な隣接マスが
**2・3・4・5番**だったとします。数字1を一つずつ見ても、
どのマスが地雷か決まりません。

しかし、両方の数字が表す地雷数は同じです。
後者にだけ含まれる2・5番に地雷があれば、後者の数字は1を超えます。
したがって **2・5番は安全** と分かります。隠された地雷配置を
読む必要はありません。

## Bendの小さな実行例

`intermediate/minesweeper/nxn_public_subset.bend` の `main` は、
公開された二つの数字を、未知の隣接マス集合と残りの地雷数に
置き換えて推論します。

```bend
def main() -> U32:
  tag(infer([3, 4], [2, 3, 4, 5], 1, 1))
```

`bend intermediate/minesweeper/nxn_public_subset.bend --check-only` で型を確認し、
`bend intermediate/minesweeper/nxn_public_subset.bend` を実行してみましょう。
期待する出力は `1` です。これは `Safe{indices}` のタグであり、
この例での `indices` は `[2, 5]` です。リストまで含む比較は
`python3 intermediate/scripts/test_nxn_public_subset.py` が行います。

## 仕組み：集合を引き算する

小さい集合を A、大きい集合を B とします。A⊆B のとき、
Aの残り地雷数が a、Bの残り地雷数が b なら、
**BからAを除いたマスには b−a 個の地雷**があります。

- `b−a=0` なら差集合のすべてが安全です。
- `b−a=|B−A|` なら差集合のすべてが地雷です。
- 差が負、または差集合のマス数を超えるなら、二つの制約は矛盾します。
- 集合が包含関係にない場合、この小さな規則は `NoMove` を返します。

Bendの `infer` は `Safe`、`Mines`、`NoMove`、
`Inconsistent` を区別します。二つの制約を同時に見ている点が、
単一数字の `nxn_public_local.bend` との違いです。

**入力の前提**：各集合は公開数字の隣接マスから既知安全・確定地雷を
取り除いた、重複のない昇順の添字です。残り地雷数も確定地雷を
差し引いた値です。プレイヤーが置いた旗は、それだけでは確定地雷では
ありません。現段階では、この集合と残り地雷数を作る処理は
Bendの二数字規則に未接続です。全frontierの列挙や一般N×Nの
運ゲー無し盤面生成を完成したとは扱いません。

## 実行結果と検証範囲

独立Pythonオラクルは、最大7個の未知マスに対して地雷配置を
すべて列挙し、二つの数字に整合する配置だけを残します。
Bendの返すタグと**添字リストの順序まで**121ケースで照合します。
この有限テストは全称証明ではなく、包含関係のない二数字を
組み合わせる一般の連立制約ソルバーもまだ未完成です。
Bendの実行結果はCI成功後に検証済みとして扱います。
