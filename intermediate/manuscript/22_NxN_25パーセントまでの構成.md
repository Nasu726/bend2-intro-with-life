# 第22章補稿：地雷率25%までのN×N盤面を構成する

> 編集用補稿。配布TeX・PDF・ZIPへの統合は未実施。対象は既存エンジンの10≤N≤100、0≤M≤⌊N²/4⌋、任意の有効な初手。長方形と一様ランダム生成は別課題。

## 必要性

先の構成はN−1個の地雷に固定されていました。実際には盤面サイズと地雷数を選べる方が便利です。地雷数を増やしたときにも、**公開数字から確実に解ける盤面**を作れるでしょうか。

ここで「ランダムに作った盤面が必ず解ける」とは主張しません。**こちらで解ける形を構成する**方法を考えます。

## Bendコード

学習用モジュールは intermediate/minesweeper/nxn_noguess_density.bend です。既存のN×Nゲームの盤面型と操作を再利用します。

~~~bend
# M=q*N+r となるように、外側のq列をすべて地雷にする
+whole = U32.div(count, n)
+remainder = U32.mod(count, n)
board = fill_columns(U32.to_nat(whole), n, right, 0, Words.new(n))
partial = fill_rows(U32.to_nat(remainder), n,
                    column_at(right, n, whole), (n - remainder : U32), board)
~~~

外側のq列を埋めたら、最後の1列の下側rマスに地雷を置きます。初手が左半分なら右端から、右半分なら左端から配置するため、初手は必ず数字0です。インターフェースは generate(n, count, first) で、対応範囲外は Unsupported{} になります。

bend intermediate/minesweeper/nxn_noguess_density.bend
python3 intermediate/scripts/test_nxn_noguess_density.py --static-only
~~~

10×10、M=25、初手0のBendデモは **112** が期待値です。これは勝利状態100と、開かれている数字2の表示コード12の和です。ただし、このデモは生成器が作った配置を知ってゲームの動作を検査します。**公開情報だけで安全性を導いた証明にはなりません。**

独立Pythonの検査では、N=10〜25についてMの許容範囲の全整数、N=26〜100について密度と端数を含む代表値を選び、計7,160局面を公開情報だけでリプレイします。Bend型検査と実行結果についてはCI成功まで未検証と扱います。

## 仕組みの説明：すべてのMに対応する構成

右端に地雷を置いた場合を説明します。M=qN+r（0≤r<N）と書くと、右側のq列はすべて地雷、その内側の列cは下側rマスだけが地雷です。

初手から地雷まで少なくとも2列以上あるため、初手0から連結した0領域が広がります。

- **r=0：** 左側の安全領域全体が0連鎖で開き、勝利します。
- **1≤r≤N−2：** 列cの上側には少なくとも2個の安全マスがあります。その左側に広がる0領域の隣接公開によって、列cの上側もすべて自動的に開き、勝利します。
- **r=N−1：** 列cの最上段1マスだけが未公開で残ります。しかしその左隣の列では、上から3番目の公開数字が3です。そこに隣接する列cの3マスは**すべて地雷と確定**します。次に最上段の公開数字1を見ると、その隣の地雷はすでに1個確定しているため、残る未公開1マスは**安全**です。その1マスをクリックすると勝利します。

これらの判断に真の地雷集合やプレイヤーの旗を使う必要はありません。N≥10、M≤⌊N²/4⌋なら、必要な地雷の列幅は約N/4以下で、初手から遠い側に十分な空間があります。左側に地雷を置く場合も左右を反転するだけです。

独立検証では public_deduce(n, opened, known_mines) に真の地雷集合を渡しません。隠された地雷の位置は、別のゲーム再生関数だけが保持します。有限テストと数学的な構成の説明は、Bendプログラムの全称形式証明とは区別します。

## 演習

10×10でMを0、9、10、19、25と変え、qとrがいくつになるか求めてみましょう。M=9と19では初手のあとに残る安全マスを、公開数字だけで特定してみましょう。初手を55に変えて地雷の配置が左右反転することも確認してみましょう。

## まだ残るもの

この方法で**条件内のどの地雷数でも確実に解ける盤面の存在と構成**を扱えます。しかし多くの盤面は初手0で即勝利し、地雷が片端に固まります。これは面白い多様な問題を作るための完成版ではありません。今後はこの構成を安全なフォールバックとして残し、ランダム候補と公開情報リプレイを組み合わせます。長方形24×48や16×30への拡張、Bend側の一般公開ソルバー、GUI接続、配布本編への統合も別途必要です。
